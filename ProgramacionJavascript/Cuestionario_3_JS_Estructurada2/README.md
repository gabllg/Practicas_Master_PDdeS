## Ejercicio 1

¿Qué diferencias existen entre una expresión y una sentencia?
  
### Respuesta  

Una sentencia asigna un valor a un identificador y puede estar compuesta por una o varias expresiones, y una expresión se compone operandos y operadores.
    
  
## Ejercicio 2
¿Qué criterio aplicas para escoger entre una sentencia while y do/while?
  
### Respuesta  
  
Utilizaría "Do while" siempre y cuando se vaya a ejecutar el código al menos 1 vez, y "While" cuando puede que se ejecute o no.

  
## Ejercicio 3


¿Qué criterio aplicas para escoger entre una sentencia for y otra iterativa?
  
### Respuesta

Escogería "for" para un bucle en el que necesite evaluar una expresión como condición para que se ejecute una sentencia, y se evalúe una segunda expresión. Por ejemplo, para recoger todos los caracteres de un string siempre y cuando cumplan las condiciones de una expresión.
  
  
## Ejercicio 4


¿Qué diferencias existen entre los valores de tipo primitivo y los valores que no son de tipo primitivo, como los arrays?
  
### Respuesta

Que los tipos primitivos no pueden contener a su vez otros tipos, son elementos únicos; los arrays sí pueden contener otros arrays.
    
## Ejercicio 5  
  
¿Qué diferencias existen entre los valores de tipo string y de tipo array?

### Respuesta  
  
Un String está formado por caracteres únicos, y un Array se compone de referencias a otros valores, es decir, guardan la información de los valores que se le asignen.
